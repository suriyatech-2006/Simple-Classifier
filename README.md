# Simple Classifier

**Author:** suriyakumar P

## Task

Train a small neural network to classify temperature readings into **Low, Medium, or High** categories.

## Categories

| Temperature | Category |
|---|---|
| Below 20°C | Low |
| 20°C - 29°C | Medium |
| 30°C and above | High |

## Project Contents

- `Simple_Temperature_Classifier.ipynb` - Google Colab notebook
- `requirements.txt` - Python dependencies

## What the Notebook Does

1. Creates labeled temperature data.
2. Builds a small TensorFlow neural network.
3. Trains the classifier.
4. Compares actual and predicted categories.
5. Tests new temperature readings.
6. Plots training accuracy.

## Example

- 15°C → Low
- 25°C → Medium
- 35°C → High
